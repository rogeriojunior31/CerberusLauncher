# First launch

The first time Cerberus opens, a short setup guide gets it ready. Every step can be skipped and changed later.

![The welcome screen](../screenshots/first-run.jpg)

## The steps

1. **Welcome.** What Cerberus does, in three cards.
2. **How you'll play.**
   - **At a desk** opens a regular window, for mouse and keyboard.
   - **On a TV** opens [Big Picture Mode](../guide/big-picture.md) in full screen every time.
3. **Where your games are.** Add the folders where you keep ROMs, disc images and game backups. Cerberus scans them and shows which of your games already have a recomp. Nothing leaves your PC.
4. **Where to install recomps.** The default is inside Cerberus's data folder. Pick another drive if you prefer; the free space is shown for each choice.
5. **Saves on any PC.** Optionally pick a folder that OneDrive, Google Drive or Dropbox keeps in sync. See [Saves](../guide/saves.md).
6. **All set.** A summary of what was found, and a button to go to the app.

**Skip setup** in the corner closes the guide at any point.

## Run it again

To see the setup guide again, go to **Settings → General → Initial setup → Show again**. It opens the next time Cerberus starts.

## Language

Cerberus speaks English and Brazilian Portuguese. It follows your Windows language. To change it, go to **Settings → Appearance → Language**.
